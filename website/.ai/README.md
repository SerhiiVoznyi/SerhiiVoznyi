# AI operating system

Canonical AI guidance for this repository lives here.

| Path                       | Purpose                                                                    |
| -------------------------- | -------------------------------------------------------------------------- |
| [`context/`](context/)     | Curated project pointers — start at [`context/index.md`](context/index.md) |
| [`rules/`](rules/)         | Conventions: engineering, design system, spread architecture, content      |
| [`agents/`](agents/)       | Per-role agent contracts (`shared/` baseline + `<role>/instructions.md`)   |
| [`skills/`](skills/)       | Reusable capability modules                                                |
| [`workflows/`](workflows/) | Multi-step playbooks                                                       |
| [`templates/`](templates/) | Skeletons for new skills, agents, and rules                                |

Repo-root [`AGENTS.md`](../AGENTS.md) is the cross-tool entry point (Cursor, Codex, Copilot, Claude Code). Keep it a short map into this folder; put policy here, not there.

Use **kebab-case** for multi-word file and folder names.
