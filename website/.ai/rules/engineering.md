# Engineering conventions

- Prefer TypeScript; match existing `src/` patterns and naming (kebab-case for files).
- Follow the repo ESLint and Prettier configs; do not fight the linter.
- Keep changes small and focused; avoid drive-by refactors unrelated to the task.
- Colocate styles with components when adding SCSS/CSS modules.
- Prefer existing libraries already in `package.json` (Mantine, React Router) over new dependencies.
