# Workflows

Multi-step playbooks agents can follow for recurring tasks.

Add one markdown file per workflow, kebab-case name. Keep steps concrete and ordered.

| Workflow                          | When to use                                                 |
| --------------------------------- | ----------------------------------------------------------- |
| [`add-spread`](add-spread.md)     | Adding a new page (spread) to the artbook                   |
| [`publish-post`](publish-post.md) | Adding or editing a blog post                               |
| [`verify-ui`](verify-ui.md)       | Checking any UI, style or effects change before handing off |
